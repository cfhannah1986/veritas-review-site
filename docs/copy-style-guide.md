# Veritas Review Site Copy Style Guide

## The rule

Write like a human reviewer, not a system describing itself. The reader should never think about HOW the review is made, only WHAT they get.

## Banned language

Never use these words or phrases on the site:

- BookBot (internal name, never public)
- AI, artificial intelligence, machine learning, ML
- Machine, automated, algorithm, system
- "Built for", "designed to" (when describing capabilities)
- "Process extracts", "claims get verified", "factual claims"
- "Actually worked" (implies surprise at capability)
- "Ran it through", "run through"
- "Train models", "training data"

## Instead

| Don't write | Write instead |
|-------------|---------------|
| "Our process extracts factual claims" | "We check every point against your manuscript" |
| "Every claim is verified" | "Every point is tied to a passage in your text" |
| "Structured review process" | "Careful review" or just describe what they get |
| "Veritas Review is built for narrative" | "We review novels, memoirs, and short stories" |
| "The system analyzes" | "We read" / "We look at" |

## Tone

- First person plural ("we") is fine
- Talk about the RESULT, not the METHOD
- "You get X" not "Our process does Y"
- If you find yourself explaining HOW, rewrite to explain WHAT

## Test

Before publishing any copy, ask: "Would a human freelancer write this?" If it sounds like a tech company describing their pipeline, rewrite it.
